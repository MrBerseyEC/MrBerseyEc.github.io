The operating system (OS) sits between the hardware, the applications and the user. It manages files, processes, peripherals and users, and provides the interface so nobody has to deal with the hardware directly.

The OS organises files into a hierarchy of folders, keeps track of where each one is stored on disk, and records details such as name, size, type and owner. Select something, then try the actions.

File permissions

File permissions control who can access a file and what they are allowed to do with it. Sally programs the robots that assemble printers. Ahmed writes the user manuals. Choose a file, set each person's permissions, then try some actions.

A single CPU core can only run one process at a time, so the OS uses a scheduling algorithm to decide which process goes next. Switching between processes quickly makes them all seem to run at once (multitasking). The OS also gives each process its own area of RAM, and takes it back when the process ends. When RAM gets full, the OS creates an area of virtual memory on the hard drive and uses a paging algorithm to swap processes out of RAM into it, and back again when it is their turn to use the CPU.

Scheduling algorithmHow it works
First in, first outProcesses queue in the order in which they arrive. The process at the head of the queue gets to use the CPU until it is finished, or is held up waiting for another resource like a printer.
Shortest job firstThe process which is closest to finishing goes next.
Round robinEach process is assigned a time slice. Processes wait their turn in a queue and the process at the head of the queue goes next. At the end of its time slice, if it isn't finished, it goes to the back of the queue and the next process is taken from the front. Some processes have a higher priority than others and get more time slices.

Open the Game to fill the RAM and watch what the OS does. A striped block on the CPU time line is a turn lost while a process is swapped back in from the hard drive, which is why a computer slows down when it runs short of RAM. Untick "Virtual memory" to see what would happen without it.

Peripherals are devices connected to the computer. The OS talks to each one through a device driver: software that translates the OS's general commands into the instructions that particular device understands. It also uses buffers so a fast CPU isn't held up by a slow device.

User interface

The OS also provides and runs the user interface: the way people interact with the computer. The two interfaces below control the same folder, so a change made in one shows up in the other. Make a folder called Work and move notes.txt into it, once with each interface.
