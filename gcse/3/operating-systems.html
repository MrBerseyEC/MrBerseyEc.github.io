Operating systems

The operating system (OS) sits between the hardware, the applications and the user. It manages files, processes, peripherals and users, and provides the interface so nobody has to deal with the hardware directly.

The OS organises files into a hierarchy of folders, keeps track of where each one is stored on disk, and records details such as name, size, type and owner. Select something, then try the actions.

A single CPU core can only run one process at a time. The OS gives each process a short time slice in turn, switching so fast that they all seem to run at once (multitasking). It also gives each process its own area of RAM, and takes it back when the process ends.

Peripherals are devices connected to the computer. The OS talks to each one through a device driver: software that translates the OS's general commands into the instructions that particular device understands. It also uses buffers so a fast CPU isn't held up by a slow device.

The OS lets several people share one computer safely. Each user has an account protected by a password. The OS checks who you are (authentication), then controls which files and settings you can access (access rights).
