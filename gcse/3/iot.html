The Internet of Things (IoT) is what you get when embedded systems are given a wireless connection to the internet. The devices collect and exchange data with little or no human involvement, and can be monitored and controlled from anywhere.

Acting on its own

An IoT device can also be programmed to act when its sensors pick up something outside the normal range, with nobody pressing anything. This room light switches itself off when no movement is detected. Each tick is one minute.

Making the battery last

Many IoT devices sit where there is no mains power, such as a sensor on a glacier or in a field, so they run on a battery. Sending data wirelessly is the most power-hungry thing they do. See how the design choices change the battery life of a soil moisture sensor.

The figures are made up to show the pattern, but the pattern is real. The programmer's choices matter as much as the battery: efficient code that does less, less often, keeps the device running for longer. Devices that must be always on, such as pacemakers, cannot simply power down, so they are designed to use very little energy all the time.

Privacy and security

IoT devices are often shipped with weak security, and many collect personal data. An attacker only needs to find one poorly secured device to get onto the network it is connected to. Choose how this smart camera is set up, then let the attacker try.

The program in most IoT devices is held in flash memory, which can be rewritten. That makes it easy to install a patch that fixes a security flaw, but without proper security it is just as easy for an attacker to reprogram the device with malware.
