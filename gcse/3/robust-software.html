Robust software

Robust software keeps working correctly, even with unexpected input or when someone deliberately tries to break it. Weaknesses in code (vulnerabilities) can be exploited by attackers, so developers look for them through code reviews, and keep audit trails to spot and investigate misuse.

Code review

In a code review, other programmers read through code looking for bugs and vulnerabilities before it is released. This program has 6 problems. Click the lines you think are a problem, then check your review.

Audit trail

An audit trail is a log the system keeps of who did what, and when. It can't stop an attack on its own, but it lets you detect unusual activity, investigate what happened, and hold people accountable. Something odd happened to the Year 10 mock grades. Use the log to find out what.
