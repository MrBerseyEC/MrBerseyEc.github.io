A computer is a machine that takes an input, processes it by following a program, and produces an output. Every computer system is made of hardware (the physical parts) and software (the programs that run on them). Phones, cars, washing machines and remote controls all contain computers.

Input, process, output

The processing is the clever part. The hardware only does anything useful because a program (software) tells it exactly what to do with each input.
