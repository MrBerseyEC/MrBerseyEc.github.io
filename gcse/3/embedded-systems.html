Embedded systems

An embedded system is a computer built into a larger device to do one dedicated job. Its program is fixed in ROM or flash memory, it takes inputs from sensors, and it controls outputs such as motors, heaters and displays. This one is a central heating thermostat.

A thermostat, running

Change the target temperature or open a window, and watch the microcontroller react. It runs the same short loop forever.

Things to notice: the program never ends and never changes; there is no keyboard or screen beyond what the job needs; and the processor only has to be powerful enough for this one task, so it can be cheap, tiny and use very little power.






  
Embedded vs general-purpose

  

    
Embedded system
    
      
  • Does one dedicated task (or a small set)
    • 
      
  • Built into a larger device
    • 
      
  • Program fixed in ROM/flash (firmware), rarely updated
    • 
      
  • Simple interface: buttons, dials, small display, or none
    • 
      
  • Low cost, small, low power
    • 
      
  • Often must respond in real time and be very reliable
    • 
    

    
General-purpose computer
    
      
  • Runs many different programs
    • 
      
  • A standalone device in its own right
    • 
      
  • User installs and updates software freely
    • 
      
  • Full interface: keyboard, mouse, touchscreen, large display
    • 
      
  • More expensive and power-hungry
    • 
      
  • Has an operating system that manages lots of applications
    •
