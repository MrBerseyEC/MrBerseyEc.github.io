Languages & translators

The CPU can only execute machine code: binary instructions for its own instruction set. Everything else has to be translated into machine code first, by an assembler, a compiler or an interpreter.

Compiler vs interpreter

Both translate high-level code into machine code, but at different times. Run both, then add an error and run again. Then press Run again without changing anything.

Interpreter

Translates one line, runs it, then moves on to the next. Translates again every time the program is run.

Lines translated: 0Time: 0.0 s

Compiler

Translates the whole program first into an executable file of machine code, then that file is run. It only needs translating again if the code changes.
