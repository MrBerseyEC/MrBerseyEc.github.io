A bitmap image is a grid of tiny blocks of colour called pixels (picture elements). Each pixel is one single colour, and that colour is stored as a binary pattern. The image file is all of those patterns, one after another.

Pixels and colour depth

The colour depth is the number of bits used to store the colour of each pixel. Pick a colour and click or drag on the grid to paint. Change the colour depth to get more colours, and watch what it does to the binary and the file size.

Colour depth

With a colour depth of n bits there are 2n possible colours. One bit gives 2 colours, which is fine for black and white. Most images today use 24 bits: 8 bits each for red, green and blue, giving 16,777,216 colours.

Quality against file size

The same picture, stored with different numbers of pixels and different colour depths. More pixels and more bits per pixel make the picture closer to the original, but the file gets bigger.

With too few pixels the image becomes pixelated: you can see the individual squares. With too few bits per pixel, smooth changes of colour turn into bands, because there are not enough colours to show the shades in between. There is no point going far beyond 24 bits, because the human eye cannot tell that many colours apart.

Image size and resolution

TermMeaningExample
PixelThe smallest element of a bitmap image. Each one is a single colour.
Image sizeThe width × height of the image, in pixels.640 × 480 is 307,200 pixels
ResolutionThe number of pixels per inch when the image is displayed. The more pixels in a given area, the more detail can be seen.A 100 × 60 image shown in the same space as a 3390 × 2000 image has far fewer pixels per inch, so it has a lower resolution
Colour depthThe number of bits used to encode the colour of each pixel.8 bits gives 256 colours

Calculating file size

File size in bits = width × height × colour depth. Divide by 8 for bytes, then by 1024 for kibibytes, then by 1024 again for mebibytes.

In the exam you are usually asked to construct an expression rather than work out the answer, for example (640 × 480 × 24) ÷ (8 × 1024) for a size in kibibytes. Images intended for the screen are nearly always compressed, so real files are smaller than this.
