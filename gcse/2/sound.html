Sound is a vibration that travels through the air as a wave. It is analogue: the air pressure changes smoothly and continuously. A computer can only store separate binary numbers, so to record a sound it measures the height of the wave thousands of times a second and stores each measurement. This is called sampling.

Sound waves

The height of the wave is its amplitude. The bigger the amplitude, the louder the sound. The number of waves per second is the frequency. The higher the frequency, the higher the pitch.

Check your volume first.

Sampling

This is one millisecond of an analogue sound. At regular intervals the amplitude is measured and rounded to the nearest level that can be stored. Change how often samples are taken and how many bits are used for each one.

A higher sample rate catches more of the changes in the wave. A higher bit depth means each sample is rounded less. Both make the stored version closer to the original, and both make the file bigger. A digital recording can never match the analogue sound completely, because whatever happens between two samples is not recorded.

Key terms

TermMeaning
AmplitudeThe height of the sound wave at a moment in time. This is what is measured and stored in each sample.
SampleOne measurement of the amplitude, stored as a binary number.
Sample rateThe number of samples taken each second, measured in hertz (Hz). 1 kHz is 1000 samples per second. CDs use 44,100 Hz (44.1 kHz).
Sample intervalThe time between one sample and the next. A higher sample rate means a shorter interval.
Bit depthThe number of bits used to store each sample. 8 bits gives 256 different levels, and 16 bits (used on CDs) gives 65,536.

Hear the difference

The same short tune, sampled in different ways. Listen for the dull, muffled sound of a low sample rate and the hiss and crackle of a low bit depth.

Calculating file size

File size in bits = sample rate × bit depth × duration in seconds.

Watch the units. A sample rate given in kHz must be multiplied by 1000, and a duration given in minutes must be multiplied by 60. For example, 3 minutes at 24 kHz with 8 bits per sample is 24 × 1000 × 8 × 3 × 60 bits.
