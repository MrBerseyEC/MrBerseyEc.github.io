A processor contains billions of transistors. Each one is a tiny switch with just two states: on or off. Binary has just two digits, 1 and 0, so it is the natural way to describe what is going on inside. Everything a computer stores or processes, including numbers, text, images, sound and the program instructions themselves, is held as a pattern of binary digits (bits).

Switches and bits

Each switch is one transistor. Click the switches to turn them on and off, or count up through every pattern.

Counting in binary: when every bit is 1, the next number needs one more bit on the left. After 111 comes 1000.

How many patterns?

Every extra bit doubles the number of different patterns. With n bits there are 2n patterns.

A group of 8 bits is a byte (256 patterns). Half a byte, 4 bits, is a nibble (16 patterns). Long patterns are usually written in groups of four so they are easier to read: 1001 0111 rather than 10010111.

How many bits do I need?

To give each item its own pattern, you need enough bits to make at least that many patterns.

Same bits, different meanings

A pattern of bits has no meaning on its own. What it represents depends on how the program has been told to interpret it. Change the bits and see five different interpretations of the same byte.

Unsigned integer

A whole number from 0 to 255

Signed integer

Two's complement, −128 to +127

Text

A character in ASCII

Image

The brightness of one grey pixel

Sound

The height of a sound wave at one moment

Numbers and text can be represented exactly. Images and sound can only be approximated: the more bits used, the closer the binary version gets to the original, but the more storage space it needs.
