Binary numbers are added in columns from right to left, just like denary numbers. In denary you carry when a column comes to more than 9. In binary you carry when it comes to more than 1.

The four rules

0 + 0 = 0write 0
0 + 1 = 1write 1
1 + 1 = 10write 0, carry 1 (this is 2 in denary)
1 + 1 + 1 = 11write 1, carry 1 (this is 3 in denary)

Adding two 8-bit numbers

Click the bits to set the two numbers, then step through the addition one column at a time, starting from the right.

Overflow error. The answer needs 9 bits, but only 8 bits have been set aside to store it. The carry out of the left-hand column has nowhere to go, so it is lost and the stored result is wrong.

Overflow

A computer sets aside a fixed number of bits to hold each number. An overflow error happens when the result of a calculation is too large to fit. This 8-bit counter stores the number of views of a video. Keep adding to it and watch what happens after 255.

This really happened. YouTube stored view counts in 32 bits as a signed number, so the largest value it could hold was 2,147,483,647. In 2014 the video for Gangnam Style passed that number, and YouTube had to change to 64 bits. Overflow errors can make programs crash or give unreliable results, so programmers have to think ahead about how much storage a value could ever need.
