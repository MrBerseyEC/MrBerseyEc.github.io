Long strings of 1s and 0s are hard for people to read, remember and copy without making mistakes. Hexadecimal (hex) is a shorthand: a base-16 number system in which one digit stands for exactly four bits. Computers do not use hexadecimal themselves. They still work only in binary.

Sixteen digits

Hexadecimal needs 16 different digits. Denary only has ten, 0 to 9, so the letters A to F are used for the values 10 to 15.

Binary to hexadecimal

Split the byte into two nibbles. Work out each nibble as a denary number, using the place values 8, 4, 2 and 1. Swap any value above 9 for its letter. Click the bits to try other patterns.

Hexadecimal to binary

Go the other way. Turn each hex digit into denary, then write each one as a 4-bit binary number and join the nibbles together.

Each digit must become four bits. The hex digit 3 is 0011, not 11. Leaving out the leading zeros in a nibble is the most common mistake.

Where you will see it: colours

A colour on screen is stored in 24 bits: 8 bits each for the amount of red, green and blue. Typing 24 bits is asking for mistakes. In hex it is just six digits, two for each colour.

The # symbol in front shows that the number is hexadecimal. Hex is also used for memory addresses, error codes and the hardware (MAC) addresses of network devices, all for the same reason: it is shorter and easier for people to work with than binary.
