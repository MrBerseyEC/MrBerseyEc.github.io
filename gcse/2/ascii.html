Pressing a key sends a pattern of 1s and 0s to the processor. For computers from different manufacturers to exchange text, they have to agree on which pattern stands for which character. ASCII (the American Standard Code for Information Interchange) is one such agreement. It uses 7 bits for each character, which gives 27 = 128 different codes.

Text to binary

Type something. Each character is stored as its own 7-bit code. The set of characters that a computer can represent is called its character set.

The ASCII table

These are the printable characters, codes 32 to 126. Codes 0 to 31 and 127 are control codes, such as new line and tab. Click any character to load it into the bits above.

■ digits 48 to 57■ upper case 65 to 90■ lower case 97 to 122

You do not need to memorise the table. The codes within each group run in order, so if you are given one code you can work out the others. If 'd' is 100, then 'c' is 99 and 'f' is 102. A lower-case letter is always 32 more than its upper-case version: 'A' is 65 and 'a' is 97.

Comparing characters

Because every character is really a number, a program can compare them with relational operators such as < and >. Strings are compared one character at a time, from the left, until two characters differ.

All the upper-case letters have lower codes than all the lower-case letters, so "Zebra" comes before "apple". This is why programs often convert text to one case before sorting it.

The limits of ASCII

The number of bits limits what can be represented. With 7 bits there are only 128 codes: enough for English letters, digits and punctuation, and nothing else.

EncodingBits per characterNumber of codesWhat it can represent
ASCII7128English letters, digits, punctuation and control codes. No é, ü, ñ or £.
Extended ASCII8256Adds some accented letters and symbols, but still far too few for the world's languages.
Unicodeup to 32over a millionCharacters from almost every writing system, plus symbols and emoji. Its first 128 codes are the same as ASCII.

More bits per character means a bigger character set, but each character can take up more storage space.
