An unsigned integer can only be zero or positive. A signed integer can be negative as well. Computers cannot store a minus sign, only 0s and 1s, so signed integers are stored using a system called two's complement, in which the most significant bit has a negative place value.

One pattern, two possible values

In 8-bit two's complement the MSB is worth −128 instead of +128. Every other place value is the same. Click the bits and compare the two interpretations.

The MSB works as a sign bit. If it is 0 the number is positive (or zero) and has the same value either way. If it is 1 the number is negative. You have to know which kind of number a pattern is meant to be before you can convert it.

Ranges

Both kinds of number have the same count of patterns. Signed numbers use half of them for negative values, so the largest positive value is about half as big.

The largest positive 8-bit value is 0111 1111 = +127. The most negative is 1000 0000 = −128. Zero counts as a positive number, which is why there is one more negative value than positive.

Negative denary to two's complement

Write the positive version in binary, flip every bit, then add 1.

The same three steps work in the other direction. To find out what a negative two's complement number is, flip the bits and add 1 to get the positive version.

Why two's complement?

Because ordinary binary addition just works, with no extra circuits for negative numbers. Add a number to its own negative and the 8 bits come out as zero.

An obvious alternative would be to keep the normal binary number and use the MSB only as a + or − sign. That method (sign and magnitude) gives two different patterns for zero, 0000 0000 and 1000 0000, and adding +2 to −2 gives −4. Two's complement was invented to make the arithmetic work properly.
