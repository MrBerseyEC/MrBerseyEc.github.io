Compression makes a file smaller by repackaging its data or by removing some of it. There are two kinds. Lossless compression keeps everything, so the original file can be rebuilt exactly. Lossy compression permanently throws some of the data away.

Why compress?

Less storage spaceMore photos, songs and videos fit on the same drive, phone or server.
Faster to transferA smaller file is quicker to upload, download or send as an attachment.
Less bandwidthStreaming and web pages use less of the network's capacity and less of a data allowance.

Lossless compression

Lossless compression works by finding data that is repeated. In this text, every word used more than once is put into a lookup table. Each time it appears, it is replaced by a short token pointing to its place in the table. Edit the text and see how the saving changes.

Lookup table

Compressed text

The sizes assume one byte for each character and one byte for each token. The lookup table has to be stored in the file as well, so text with little repetition hardly shrinks at all. Lossless compression is essential when every bit matters, such as a text document, a spreadsheet or a program: losing words from a report or lines from a program would be a serious problem.

Lossy compression

Lossy compression removes detail that people are unlikely to notice. A photograph contains tiny differences in colour that our eyes cannot tell apart. Here, a pixel that is nearly the same colour as the one before it is given exactly the same colour. Long runs of identical pixels can then be stored using far fewer bits. Increase the compression until you can see the damage.

Original

After lossy compression

The removed data is gone for good. There is no way to get the original back from the compressed file. Sound is compressed in the same way: an MP3 leaves out frequencies we cannot hear and differences in volume too small to notice.
