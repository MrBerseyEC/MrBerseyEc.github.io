Each device on a network, whether it is a phone, a printer, a router or a smart light bulb, is called a node. A network topology describes how the nodes are connected to one another. Three common topologies are bus, star and mesh.

Collisions on a bus

Only one message at a time can travel along the shared cable of a bus network. If two devices send at the same moment the signals collide, and both messages become unreadable. Bus networks deal with this using CSMA/CD: Carrier Sense, Multiple Access with Collision Detection.

  1. Check if the bus is busy.
  2. If it is not busy, send the message. Otherwise go back to step 1.
  3. Listen to see if the message was received correctly.
  4. If it was, go back to listening for messages. If it was not, go to step 5.
  5. Wait a random amount of time, then go to step 1 to retry.

The wait has to be random. If both devices waited the same length of time, they would simply collide again, and again. The more devices there are on a bus, the more collisions happen and the slower the network runs.

Comparing the topologies

BusStarMesh
How it is connectedEvery node is attached to a single cable, the backbone, with a terminator at each endEvery node is connected directly to a central node, usually a switchEach node is connected to several others. In a fully connected mesh, every node is connected to every other node
Fault toleranceIf one node fails the rest carry on, but if the backbone is cut or damaged the whole network stopsA failed node or cable affects only that node, but if the central node fails the whole network stopsVery fault tolerant. If a node fails, messages are re-routed
SecurityEvery node sees all the data traffic, which may be a riskData is sent only to the intended recipient, without passing through other nodesData may hop through other nodes on its way
ScalabilityEasy to add devices, but each one means more collisions and a slower networkNodes can be added and removed without taking the network offline. The capacity of the central node sets the limitVery scalable. Any number of nodes can be added without taking the network offline
PerformanceGets worse as more devices are addedDepends on the capacity of the central nodeVery high, because there are many routes
CostCheap. Very little cable is neededA wired star needs a lot of cable, so it is more difficult and expensive to set upA fully connected wired mesh is difficult and expensive to install. This is not an issue for wireless mesh networks
Where it is usedRare in computer networks now. Almost every modern car uses a bus (the CAN bus) to link its sensors and controlsThe most widely used. Most home networks are a star, with the wireless router as the central nodeIoT devices such as smart lighting, traffic management in smart cities, and the backbone of the internet

Networks with a single topology are rare. Most are hybrid, combining elements of different topologies. The internet is the ultimate hybrid network.
