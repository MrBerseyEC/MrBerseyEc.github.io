TCP/IP is a collection of protocols that sets out exactly how data is formatted and transmitted across networks, including the internet. The protocols are organised into four layers, known as a protocol stack. Each layer has one job to do, and passes the data on to the layer next to it.

Down the stack and back up

Computer A asks for a file from computer B. Data passes down through the four layers when it is sent, and back up through them in reverse order when it is received. Step through to see what each layer adds or removes.

The four layers

LayerWhat it doesProtocols
ApplicationDefines how user services such as web browsers and email operate. This is the layer the user's software talks toHTTP, HTTPS, FTP, SMTP, POP3, IMAP
TransportSets up a channel between the source and destination devices. Splits outgoing data into packets and reassembles incoming packets, checking that they are correct. It does not know what the data representsTCP
Internet
(also called the network layer)		Adds the source and destination IP addresses to the packets it gets from the transport layer, and routes them to the recipientIP
Link
(also called the network interface layer)		Defines how data is physically transferred from one device to the next, the whole way along the route: network card to switch, switch to router, router onwardsEthernet (wired LANs), Wi-Fi (wireless LANs)

In practice the packets take different routes. The transport layer creates the impression of a single dedicated channel, and leaves the details of how packets actually travel to the layers below it.

Why use layers?

  • Each layer has one clear function, and only needs to know how to pass data to the layers directly above and below it.
  • A layer can be changed without affecting the others. Swapping a cable for Wi-Fi changes the link layer only: the browser carries on exactly as before.
  • Hardware and software from different suppliers work together, because they all follow the same standard. Without it each supplier would need its own customised system.
