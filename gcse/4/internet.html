The word internet is short for interconnected network. It is a network of networks, large and small, some privately owned and some public, that together link billions of devices around the world. No single organisation or government owns it.

Each major telecommunication company has its own internet backbone. Network Access Points (NAPs) join the backbones together to form a worldwide mesh, so there are many possible routes between any two places.

IP addresses

Every device connected to the internet is given an IP address, which uniquely identifies it on the network. An IPv4 address is 32 bits long. To make it easier for people to read, it is written as four denary numbers from 0 to 255, one for each byte, separated by dots. Change the numbers to see the bits the computer actually uses.

Four billion addresses seemed more than enough when IPv4 was invented in the 1970s. It is nowhere near enough now, which is why IPv6 was introduced.

Static and dynamic addresses

The router gets one public IP address from the ISP. It then gives each device on its own network a local IP address, which is only visible inside that network. This router has a pool of five addresses to hand out. Click devices to connect and disconnect them.

Domain names

People are better at remembering words than numbers. The Domain Name System (DNS) lets you type a name, and looks up the IP address that belongs to it.
