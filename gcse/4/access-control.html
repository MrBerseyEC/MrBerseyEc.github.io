Access control decides who can log in to a network, and what each authorised user can see and do once they are in. It starts with authentication: checking the identity of the person who is trying to gain access.

Multi-factor authentication

A username and password is the most basic form of authentication. Many organisations ask for more than one kind of proof. Choose what this network asks for, and what an attacker has managed to get hold of.

To log in, a user must provide

a password or a PIN a swipe card, an electronic key fob or a code sent to their phone a fingerprint, a face or a voice

The attacker has

obtained with a phishing email stolen from a bag a physical attribute is very hard to supply

Someone attempting to gain unauthorised access may be able to meet one or two of the requirements, but would struggle to supply a matching physical attribute. Each extra factor means one more thing an attacker has to get hold of.

How long would a password last?

A brute force attack tries every possible password until one works. The longer the password and the more kinds of character it uses, the more possibilities there are to try.

The time assumes an attacker who can try ten billion passwords a second, which is realistic for stolen password data. It only applies to random passwords: a real word, a name or a date falls much faster, because attackers try those first.

File permissions

Being logged in does not mean being able to open everything. This is a hotel's network. Choose who is logged in, then try to do things with each file.

The principle of least privilege: give each user only the permissions and administrative rights they need to do their job. A receptionist needs the booking system, but not the revenue forecasts. Access controls are set up by the organisation's system administrator.

Physical security

Anyone with physical access to a server, and enough technical skill, could bypass the authentication and access control systems altogether, then copy, change or delete data or install malware. So the servers are kept in a locked server room. Swipe a card to try the door.
