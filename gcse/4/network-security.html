The goal of network security is to protect a network and its data from threats, both from inside the organisation and from outside it. A security threat is any incident, malicious or unintended, that causes disruption, damage or data loss: a hacker stealing data, or simply an employee who clicks on a link in an email and downloads a virus.

Three things to protect

ConfidentialityA network holds sensitive data about people, products and performance. Only people who are authorised should be able to access it.
CorrectnessData is useless if it is wrong. Access must be controlled so that only those who need to can view and edit it. Imagine an error in your health records.
AvailabilityA network is useless if the data cannot be reached when it is needed. Hardware fails, there are fires and floods, and criminals may try to take the network offline.

Run a penetration test

To keep a network secure, an organisation first has to find its weak spots. You are an ethical hacker, hired by a company to carry out simulated attacks on its own network. Run each test, then fix what you find and test again.

Report for the company

Penetration testing (pen testing) looks for technical weaknesses, and also tests how security-aware the staff are, using social engineering tactics to see how easily they are tricked. When the testing is complete, the ethical hacker produces a report listing the vulnerabilities discovered and advising how to deal with each one.

Not all hackers are criminals

Two real examples

WannaCry
2017		A ransomware attack that spread across the internet and infected more than 230,000 computers in over 150 countries. Users were locked out and their data was encrypted. A ransom was demanded to release it. The NHS was badly affected.An attack on availability. Data that cannot be reached is as bad as data that has been lost.
Heartbleed
2014		A vulnerability in OpenSSL, software used to secure network connections, caused by insufficient input validation. A security patch was released quickly, but it took time for every website to apply it, and data was stolen in the meantime.Once a vulnerability is identified it has to be fixed everywhere. Systems that are not kept up to date stay vulnerable.
