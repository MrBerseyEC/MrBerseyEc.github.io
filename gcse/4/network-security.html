The goal of network security is to protect a network and its data from threats, both from inside the organisation and from outside it. A security threat is any incident, malicious or unintended, that causes disruption, damage or data loss: a hacker stealing data, or simply an employee who clicks on a link in an email and downloads a virus.

Run a penetration test

To keep a network secure, an organisation first has to find its weak spots. Run each test, then fix what you find and test again. Then switch to the criminal and run the same tests: the techniques are identical, but what happens next is not.

Report for the company

Penetration testing (pen testing) looks for technical weaknesses, and also tests how security-aware the staff are, using social engineering tactics to see how easily they are tricked. An ethical hacker works with the organisation's permission and reports every vulnerability with advice on fixing it. A criminal hacker has no permission and keeps what they find secret, to use or sell.

Why a fix has to reach every machine

In 2017 the WannaCry ransomware spread across the internet and infected more than 230,000 computers in over 150 countries, including many in the NHS. It used a flaw in Windows that already had a security patch. Only the computers that had not installed the patch were infected. The same lesson came from Heartbleed in 2014, a flaw in OpenSSL caused by insufficient input validation. A patch was released quickly, but it took time for every website to apply it, and data was stolen in the meantime. Once a vulnerability is known, every system that has not been updated is a target.
