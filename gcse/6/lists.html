A variable holds one value. A list holds many values under a single name, in order. Each item has a numbered position called its index, so a program can store thirty marks in one list instead of thirty separate variables. In Python, a list is used wherever another language would use an array.

Index explorer

This is the list pets = ["cat", "dog", "fish", "hamster", "rabbit"]. The small number above each item is its index. Click an item to see the code that would fetch it.

Indexes start at 0, not 1. A list with 5 items has indexes 0 to 4, so the last index is always one less than the length.

Adding and removing items

Lists can grow and shrink while the program runs. append() adds to the end, insert() adds at a chosen index and shuffles everything after it along, and del removes the item at an index.

CodeWhat it does
aList = []Creates an empty list
len(aList)Returns the number of items
aList.append(item)Adds the item to the end
aList.insert(index, item)Inserts the item just before the one currently at that index
del aList[index]Removes the item at that index
