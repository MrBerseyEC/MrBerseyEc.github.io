Sometimes you can't know in advance how many times a loop should repeat: keep asking until the password is right, keep playing until the lives run out. A condition-controlled loop repeats for as long as a condition is true. In Python that is a while loop.

How a while loop works

Python checks the condition. If it is true, the indented body runs, and then Python goes back up and checks the condition again. As soon as the condition is false, the loop ends and the program carries on underneath.

  • What value does count have when the loop ends? Check the table.
  • Change the condition to count >= 0. What extra line appears?
  • Make it count down in twos from 20.
  • Make it count up from 1 to 5. You need to change three things.

A while loop needs three things: a starting value (line 1), a condition that uses it (line 3), and something inside the loop that changes it (line 5).

A while loop checks its condition before each repetition. If the condition is false the very first time, the body does not run at all.
