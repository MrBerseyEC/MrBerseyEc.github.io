A variable is a named place in memory that holds a value, and the value can change while the program runs. A constant is a named value that is set once and should not change. On this page, each program shows a table of its variables when it finishes, so you can see exactly what ended up in memory.

Assignment

The = sign means "becomes". Python works out the value on the right, then stores it under the name on the left. Assigning to the same name again replaces the old value.

Constants

A constant is a value that is fixed while the program runs, like a VAT rate or the number of players in a team. By convention, constants are named in capital letters and set at the top of the program. They make code easier to read, and if the value ever needs updating you only change it in one place.

  • Ticket prices go up to £9.25. How many lines do you need to change?
  • Rewrite line 6 without the constant, as tickets * 8.5. Which version is easier to understand?
  • Add a constant BOOKING_FEE of £1.50 that is added once to every order.

Python doesn't actually stop you changing a constant. The capital letters are a signal to other programmers: this value is not meant to change.
