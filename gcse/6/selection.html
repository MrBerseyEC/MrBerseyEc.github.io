Selection lets a program choose which lines to run. It asks a question that is either true or false, then follows a different path depending on the answer. In Python, selection is written with if, elif and else.

Conditions: questions with a True or False answer

A condition compares two values using a relational operator. The result is always a Boolean: True or False.

One equals sign (=) stores a value. Two equals signs (==) ask whether two values are the same. Mixing them up is one of the most common mistakes.

if

The indented lines under an if only run when the condition is true. The line needs a colon at the end, and the indentation (4 spaces) is how Python knows which lines belong to the if.

if ... elif ... else

When there are more than two paths, use elif (short for "else if"). Python checks the conditions from the top and runs the block for the first one that is true, then skips the rest. The else at the end catches everything that is left.

Combining conditions: and, or, not

Logical operators join conditions together. With and, both sides must be true. With or, at least one side must be true. not flips true to false and false to true.

Selection inside selection

An if can go inside another if. This is called nesting. The inner question is only asked when the outer condition was true. Each level is indented by another 4 spaces.
