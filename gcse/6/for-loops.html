Count-controlled repetition

Repetition means running the same lines of code more than once. When you know in advance how many times to repeat, use a count-controlled loop. In Python that is a for loop with range(), which counts for you.

Repeating a fixed number of times

The indented lines under the for are the body of the loop. They run once for every number that range() produces. Lines that are not indented run once, after the loop has finished.

  • Make it say hello 12 times.
  • Indent line 4 so that it is inside the loop. What changes?
  • How many lines of output would range(0) give? Predict, then test.

The loop variable

Each time round the loop, the variable after for (here it is called count) holds the next number from the range. You can use it inside the loop like any other variable.

  • What is the first number displayed? What is the last? Is 5 ever displayed?
  • Change line 2 to print(count + 1).
  • Change line 2 to print(count * count).
  • Rename the variable to lap in both places. Does the program still work?

range(5) produces five numbers, 0, 1, 2, 3 and 4. It starts at 0 and stops before it reaches 5.

Range explorer

range() can take up to three values: where to start, where to stop (it never includes this number), and the step between numbers. Change the values to see which numbers the loop would count through.

  • Make it count from 1 to 10.
  • Make it produce the even numbers from 2 to 20.
  • Make it count down from 10 to 1. You will need a negative step.
  • Find three different settings that produce no numbers at all.

Start, stop and step in a program

Using the loop variable in a calculation

The loop variable is most useful when each repetition needs to do something slightly different.

  • Make the table go up to 20 times.
  • Ask the user how far the table should go, and use their answer as the stop value. Careful: the stop value is not included.

Keeping a running total

A very common pattern: set a total to zero before the loop, add to it inside the loop, and use it after the loop.

A loop inside a loop

Loops can be nested. For each single turn of the outer loop, the inner loop runs all the way through.

Looping over a string or a list

A for loop can also visit every item in a data structure, one at a time. This is called iteration. There is no range(): the loop variable holds each item in turn.
