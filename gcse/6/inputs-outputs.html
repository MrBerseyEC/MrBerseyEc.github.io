Inputs and outputs

Almost every program takes something in, does something with it, and sends something out. In Python, print() displays output on the screen and input() collects what the user types on the keyboard. Every box of code on this page is real Python: change it, press Run, and see what happens.

Output with print()

Python runs one line at a time, from the top to the bottom. print() displays whatever is inside its brackets. Text (a string) needs quote marks around it. Numbers and calculations do not.

  • Delete one of the quote marks on line 1 and run it. Read the error message, then fix it.
  • Swap two lines over. Does the order of the output change?

Input with input()

input() displays a prompt, waits for the user to type something and press Enter, then hands back what they typed. Store the answer in a variable so you can use it later. When you run this, type your answer into the highlighted box in the output.

  • Remove the space at the end of the prompt, just before the closing quote mark. What changes?
  • What happens if the user just presses Enter without typing anything?

input() always gives you a string

Even if the user types a number, input() returns it as text. This program has a bug. Run it, type your age, and read the error.

Python can't add the number 1 to a piece of text. The fix is to convert the input: int() for whole numbers, float() for numbers with a decimal point. To join a number onto text for printing, convert it back with str().

  • Type fifteen as your age. What error do you get, and why?
  • Take the str() off line 3 and run it. Which error comes back?
  • Type 1.5 for the age question. Why doesn't int() like it?

Building an output message

There are two ways to mix text and values in one line of output. You can join strings with + (concatenation), or you can write a string with {} placeholders and fill them in using .format().

  • Compare the two "Total" lines. What did {:.2f} do to the number?
  • Change .2f to .0f, then to .3f.
  • Change the price to 4.99. Which total looks more like a real receipt?

Lining output up in columns

A placeholder can also set how wide a value should be and which side it sits on. < is left aligned, > is right aligned and ^ is centred. The number after it is the width in characters. Multiplying a string repeats it, which is handy for drawing lines.

PlaceholderMeaning
{}Put the next value here
{:<10}Left aligned in a space 10 characters wide
{:>5}Right aligned in a space 5 characters wide
{:^9}Centred in a space 9 characters wide
{:.2f}A real number shown with exactly 2 digits after the decimal point
{:8.2f}8 characters wide, with 2 digits after the decimal point
  • Change {:<10} to {:>10} on line 1. What moves?

  • Make the first column wider so that "Strawberry milkshake" would fit.
