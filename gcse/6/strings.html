A string is a sequence of characters: letters, digits, spaces and symbols. Names, passwords, postcodes and messages are all strings. Because a string is a sequence, each character has an index, and Python has plenty of built-in tools for measuring, cutting, searching and changing text.

Searching, replacing and splitting

find() returns the index where some text first appears, or -1 if it isn't there. replace() swaps every occurrence. strip() trims unwanted characters from both ends. split() breaks a string into a list.

Characters are numbers underneath
