Truth table at a rising edge: Qnext = D. At any other time (CLK high, low, or falling), Q holds its value.

A flip-flop is not a new kind of component. It is ordinary logic gates, wired so that outputs loop back into inputs. Build it up in three steps; each one fixes a problem with the step before.

Step 1: a loop that remembers

Every circuit you have met so far is combinational: the outputs depend only on the inputs right now. Here each NOR gate's output is also an input to the other gate, and that changes everything. Set S to 1, then back to 0. Q stays at 1, because the loop holds itself in place. That is one bit of memory, made from two gates.

S sets Q to 1 and R resets it to 0. (A NOR gate is an OR followed by a NOT: it outputs 1 only when both inputs are 0.)

The problem. Storing a bit takes two separate inputs, and one combination is broken. Try S = 1 and R = 1 together: both outputs go to 0, so Q̅ is no longer the opposite of Q.

Step 2: one data input and an enable

The same latch, with three gates in front of it. S is driven by D and R by NOT D, so they can never both be 1: the broken combination is now impossible. The AND gates only let S and R through while EN is 1.

So with EN = 1 the latch is transparent and Q follows D. With EN = 0 it is shut and Q holds, whatever D does.

The problem. Q follows D for the whole time EN is high, not just for an instant. That is fatal as soon as an output feeds back to its own input, which is exactly what a counter does (new value = old value + 1). Press Wire Q̅ back to D, then set EN to 1: each change to Q changes D, which changes Q again, and it never settles.

Step 3: two latches on opposite halves of the clock

Each box is the whole circuit from step 2. Green means that latch is open.

Put two D latches in a row and give the first one the inverted clock. It works like an airlock: one door is always shut, so nothing can pass straight through.

CLK = 0. The first latch (the master) is open and tracks D. The second (the slave) is shut, so Q does not move.
CLK rises. The master shuts, freezing whatever D was at that instant. The slave opens and passes that value to Q.
CLK = 1. D can change as much as it likes. The changes stop at the master's shut door.
CLK falls. The slave shuts, still holding Q, and the master opens again.

The only moment Q can change is the rising edge, and the value it takes is the one D had at that edge. That is the behaviour on the first tab, and this is where it comes from.

Now press Wire Q̅ back to D and toggle CLK a few times. The loop that ran away in step 2 is tamed: Q flips exactly once per rising edge, so it changes at half the clock's frequency. Chain several of these together and you have a binary counter.

Going further. The master needs D to be steady for a short time before it shuts (the setup time) and just after (the hold time). Each gate also takes a few nanoseconds to respond, and those delays are what limit how fast a processor's clock can run. Real chips usually build the two latches from fewer transistors than this, but the master and slave idea is the same.
