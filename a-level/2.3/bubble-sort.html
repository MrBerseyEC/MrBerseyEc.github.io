A bubble sort puts a list in order by comparing neighbouring items and swapping any pair that is the wrong way round. Larger items "bubble" towards the end of the list on every pass. It is simple to write but slow on long lists.

How it works

  1. Start at the first item and compare it with the item next to it.
  2. If the first is larger than the second, swap them. Otherwise leave them.
  3. Move along one place and compare the next pair. Carry on until the end of the list is reached. This is one pass.
  4. After a pass, the largest item that was still unsorted has reached its final place at the end. The next pass can stop one place sooner.
  5. Keep a flag, swapped, that is set to false at the start of each pass and to true whenever a swap is made.
  6. Repeat passes until a whole pass is made without any swap. The list is now in order.
  • It works in place: it needs no second list, only a temporary variable for a swap.
  • Without the swapped flag it would always make every pass, even on a list that is already sorted.
  • A list with n items needs at most n − 1 passes.
  • It only ever compares and swaps neighbours, which is why an item near the end that belongs at the start has to move one place per pass.
