A merge sort is a divide and conquer algorithm. It splits the list in half again and again until every part has a single item, which is trivially sorted, and then merges the parts back together in order. It is much faster than a bubble or insertion sort on long lists, but it needs extra memory.

How it works

  1. If the list has only one item it is already sorted. Stop. This is the base case.
  2. Otherwise divide the list into two halves at the middle.
  3. Merge sort the left half, then merge sort the right half. Each call splits its list again, so this is recursive.
  4. Merge the two sorted halves into one sorted list. Compare the first unused item in each half and copy the smaller one into a new temp list. Repeat.
  5. When one half runs out, copy whatever is left of the other half to the end of temp.
  6. Copy temp back into the original positions. This part of the list is now sorted.
  • Merging two sorted lists is quick, because only the front item of each needs to be compared, so the whole merge is one pass.
  • Using <= in the comparison keeps equal items in their original order, so the sort is stable.
  • Its speed does not depend on the starting order: a sorted, reversed or random list all take about the same time.
  • It needs a temporary list as long as the part being merged, so it uses more memory than the other sorts.
