A linear search finds an item by looking at every item in turn, from the start of the list, until it finds the target or runs out of items. It is the simplest searching algorithm and it works on any list, sorted or not.

How it works

  1. Start at the first item in the list.
  2. Compare the item with the target, the value being looked for.
  3. If they are equal, stop. The target has been found, and the position of the item is returned.
  4. If not, move on to the next item and repeat from step 2.
  5. If the end of the list is reached without a match, the target is not in the list. A value that cannot be a position, such as −1, is returned to show this.
  • The list does not need to be sorted.
  • It needs no extra memory and is easy to write and to test.
  • It can be used on any structure that can be read in order, such as an array or a linked list.
  • On a long list it is slow, because every item might have to be checked.
