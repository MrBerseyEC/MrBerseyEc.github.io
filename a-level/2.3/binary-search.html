A binary search finds an item in a sorted list by repeatedly looking at the middle item and throwing away the half that cannot contain the target. Each step halves the number of items left to search, so it is very fast on long lists.

How it works

  1. The list must already be sorted.
  2. Set low to the first position and high to the last position.
  3. Find the middle: mid = (low + high) DIV 2.
  4. Compare the middle item with the target. If they are equal, the target is found.
  5. If the middle item is smaller than the target, the target can only be in the upper half, so set low = mid + 1. If it is larger, the target can only be in the lower half, so set high = mid - 1.
  6. Repeat from step 3. If low becomes greater than high there are no items left, so the target is not in the list.
  • It only works if the list is sorted. On an unsorted list it may discard the half that holds the target.
  • It needs direct access to the middle item, as an array provides.
  • A list of 1 000 000 items needs at most 20 comparisons, where a linear search could need 1 000 000.
  • Doubling the length of the list adds just one more comparison.
