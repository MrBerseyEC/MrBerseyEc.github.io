An insertion sort builds a sorted list one item at a time, in the same way that most people sort playing cards in their hand. Each new item is slotted into its correct place among the items that are already sorted.

How it works

  1. The first item on its own is a sorted list of one item.
  2. Take the next item from the unsorted part. Call it the current item and hold it to one side, leaving a gap.
  3. Compare the current item with the sorted items, working from right to left. Each item that is larger than the current item is shifted one place to the right, and the gap moves left.
  4. Stop when an item is not larger than the current item, or when the start of the list is reached.
  5. Put the current item into the gap. The sorted part is now one item longer.
  6. Repeat for every remaining item. When the last one has been inserted the list is in order.
  • It sorts in place: only the current item is held outside the list.
  • Items are shifted, not swapped, so each shift is a single assignment.
  • If an item is already in the right place the inner loop stops at once, so a list that is nearly sorted is sorted very quickly.
  • It is a good choice for short lists, and for lists that are already nearly in order.
