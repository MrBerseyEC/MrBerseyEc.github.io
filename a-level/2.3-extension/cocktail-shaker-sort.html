A cocktail shaker sort is a bubble sort that works in both directions. A forward pass bubbles the largest unsorted item to the right, then a backward pass bubbles the smallest unsorted item to the left, so the unsorted window shrinks from both ends on every cycle. It fixes bubble sort's weakness with small items stuck near the end of the list, sometimes called "turtles".

How it works

  1. Keep two bounds, left and right, marking the unsorted window. They start at the two ends of the list.
  2. Forward pass: compare neighbours from left to right, swapping any pair the wrong way round. The largest item left ends up at right, so move right one place in.
  3. Backward pass: compare neighbours from right back down to left, swapping any pair the wrong way round. The smallest item left ends up at left, so move left one place in.
  4. Keep a swapped flag, as in a bubble sort, so a cycle with no swaps at all stops the sort early.
  5. Repeat forward and backward passes until a whole cycle makes no swap, or the window closes.
  • A plain bubble sort only ever pushes large items one way. A small item near the end still has to wait for a whole pass to move it just one place left — these slow-moving small items are called turtles.
  • The backward pass gives turtles a free ride all the way to the front in a single pass, instead of one place at a time.
  • It is still in place and stable, just like a bubble sort, since it only ever swaps a strictly-out-of-order neighbouring pair.
  • It still has an O(n²) worst case — it is not faster overall, just better balanced on certain inputs.
