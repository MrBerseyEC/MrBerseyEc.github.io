A counting sort never compares two items with each other. Instead it counts how many times each possible value appears, then uses those counts to write every item straight into its final position. It is extremely fast, but only works when the values are whole numbers from a known, fairly small range.

How it works

  1. Find the largest value, maxVal, in the list.
  2. Create a count array with one place for every value from 0 to maxVal, all starting at 0.
  3. Scan the original list once. For every item, add one to the count at that value's index: counts[value].
  4. The count array now holds how many times each value appears.
  5. Rebuild the list in order: for each possible value, from smallest to largest, write it out counts[value] times.
  • No two items are ever compared, so this is not a comparison sort — it sidesteps the O(n log n) limit that applies to sorts like merge sort.
  • Its speed depends on k, the range of possible values, as well as n, the number of items: it takes O(n + k) time.
  • It only works on data that can be counted this way, such as whole numbers, grades, or ranks — not arbitrary text or decimals.
  • If k is much larger than n, most of the count array is wasted on zeros, so it stops being a good choice.
