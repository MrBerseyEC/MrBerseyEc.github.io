A radix sort sorts whole numbers one digit at a time, starting with the units digit, using 10 buckets numbered 0 to 9. After every digit the buckets are collected back into a list, and the next digit is used, until even the most significant digit has been processed. Like counting sort, no two items are ever compared directly.

How it works

  1. Find the largest value in the list, to know how many digits to process.
  2. Starting with digit = 1 (the units place), create 10 empty buckets, numbered 0 to 9.
  3. For every item, work out that digit's value: (value DIV digit) MOD 10. Add the item to the back of that bucket.
  4. Collect the buckets back into one list, in order from bucket 0 to bucket 9.
  5. Multiply digit by 10 (move to the next digit: tens, then hundreds, and so on) and repeat from step 2.
  6. Stop once digit is bigger than the largest value. The list is now fully sorted.
  • Each pass over one digit is really a stable counting sort keyed on that digit, so items that share a bucket keep the order they arrived in.
  • That stability is essential: a later, more significant digit relies on an earlier pass having already put the less significant digits in order.
  • No two items are ever compared with each other — only sorted by one digit's value — so this is not a comparison sort.
  • The number of passes depends on how many digits the largest value has, not on how the list starts out.
